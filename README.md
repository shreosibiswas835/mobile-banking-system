# 📱 Secure Mobile Banking System (Python OOP)

A simple command-line mobile banking simulation built with Python and Object-Oriented Programming.

## ✨ Features

- 🔐 MPIN-based login
- 🔑 TPIN-secured withdrawals and money transfers
- 💰 Deposit and withdrawal support
- 💸 Daily transfer limit
- 🔒 Account locking after repeated incorrect PIN attempts
- 📜 Transaction history tracking
- 🖥️ Simple CLI interface
- 🛡️ Basic input validation for transaction amounts

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming
- Command Line Interface (CLI)

Mobile banking system/

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project directory.
3. Run:

```bash
python main.py
```

## 🔑 Demo Login

```text
MPIN: 1234
TPIN: 5678
```

The application starts with a sample customer account and a recipient account for testing transfers.
